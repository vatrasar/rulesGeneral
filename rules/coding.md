# Code Rules

## Coding rules

1. You are a highly skilled software engineer who prioritizes clean, robust bash code.

2. Keep functions and scripts short and modular. Your primary goal is to write clean, flat code without unnecessary nesting.

3. Language Requirements:
   All variable names, function names, and comments within scripts must be in English.

4. Surgical Changes:
   **Touch only what you must. Clean up only your own mess.**
   When editing existing code:
   - Don't refactor things that aren't broken.
   - Match existing style.
   - Clean up any unused code caused by your changes.

5. **File Length Limits:** Files should not exceed 600 lines, and ideally should stay under 300 lines. If you intend to create or expand any script file beyond 600 lines, you MUST ask for and obtain explicit permission from the user beforehand. It is far better to have many small, specialized helper scripts and functions than a single monolithic giant.
